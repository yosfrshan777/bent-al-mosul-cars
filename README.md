# بنت الموصل للسيارات — نسخة حقيقية قابلة للتشغيل

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. غيّر `JWT_SECRET` إلى قيمة طويلة عشوائية.
4. ضع بريد وكلمة مرور قوية للمدير في `ADMIN_EMAIL` و`ADMIN_PASSWORD`.
5. شغّل:
   ```bash
   npm install
   npm start
   ```
6. افتح `http://localhost:3000`.

## الموجود فعلياً
- تسجيل وإنشاء حساب.
- كلمات المرور مخزنة كـ bcrypt hash.
- جلسات JWT.
- صلاحية admin منفصلة.
- SQLite مع WAL وForeign Keys.
- رفع صور مع نوع وحجم محدودين.
- Rate limiting.
- Helmet وCORS وCompression.
- إضافة سيارة مع خطط 10,000 / 20,000 / 30,000 د.ع.
- الإعلانات الجديدة Pending وتحتاج موافقة الإدارة.
- لوحة إدارة لاعتماد/حذف الإعلانات.
- طلب دفع يُسجل في قاعدة البيانات.

## مهم قبل النشر التجاري
الدفع هنا ليس بوابة دفع عراقية حقيقية بعد؛ يحتاج ربط مزود دفع فعلي وحساب تاجر ومفاتيح سرية محفوظة في متغيرات البيئة. كذلك يجب تشغيل الموقع خلف HTTPS، ووضع قاعدة البيانات والملفات على خدمة تخزين/خادم موثوق، وإضافة نسخ احتياطية ومراقبة وسجل تدقيق و2FA للمدير.


## الدفع اليدوي
الإعلان العادي 10,000 د.ع. المستخدم يرفع إيصال التحويل مع الإعلان، ويظهر رابط الإيصال في لوحة الإدارة؛ النشر لا يتم إلا بعد موافقة المدير. في الإنتاج، الأفضل استخدام حساب تجاري مخصص وعدم وضع أي PIN/CVV داخل التطبيق.
